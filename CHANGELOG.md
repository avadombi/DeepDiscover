# Changelog

## 1.0.0

First public release of DeepDiscover for water-quantity modeling.

- Conservative DiscoverUnits with Causal Relationship Constraints.
- Multiple hydrological sources, losses, finite storage capacities and overflow.
- Instantaneous, fixed, learned and state-dependent temporal routing.
- Optional informational memory, snow accumulation and melt.
- Streamflow, groundwater level and other observation operators.
- Multivariable calibration, custom loss functions and numerical diagnostics.
- CAMELS-US and synthetic examples, documentation and tests.
