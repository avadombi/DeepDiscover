# DeepDiscover

DeepDiscover provides conservative differentiable hydrological modeling with one or more DiscoverUnits. The library works with quantities of water, learned release relationships, explicit boundaries and declared route destinations. Simulated storages and fluxes can be related to measured variables through observation operators.

Start with [installation](installation.md) and [getting started](getting_started.md). The [scientific formulation](scientific_formulation.md) gives the governing equations, while [custom components](customization.md) explains extensions.

The library models water quantities. Trace transport and isotope simulations require separate components.
