# DeepDiscover

DeepDiscover is a Python library for hydrological model discovery with one or more conservative, differentiable DiscoverUnits. The library works with quantities of water, learned release relationships, explicit boundaries and declared route destinations. Simulated storages and fluxes can be related to measured variables through observation operators.

Start with [installation](installation.md) and [getting started](getting_started.md). The [scientific formulation](scientific_formulation.md) gives the governing equations, while [custom components](customization.md) explains extensions.
