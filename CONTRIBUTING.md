# Contributing

Bug reports, documentation corrections and suggestions are welcome through [GitHub Issues](https://github.com/avadombi/DeepDiscover/issues). Before opening an issue, check whether the same problem has already been reported.

When reporting a problem, provide:

- The Python, TensorFlow and Keras versions.
- The operating system and installation method.
- The model configuration and input shapes.
- A small example that reproduces the problem.
- The complete error message and the expected behaviour.

Please do not attach confidential data, access tokens or unpublished research files.

For proposed code changes, include tests covering the affected behaviour. Changes to physical components should include numerical conservation checks. Use descriptive names and keep hydrological equations visible in the implementation.
